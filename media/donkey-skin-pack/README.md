# GK2 Saddle Up: Donkey Skins, media

Pictures for the pack's own pages (the Nexus Mods page of GK2 Saddle Up: Donkey Skins). The rules of `../README.md`
hold: one file per subject, named by the subject, re-shot in place; hotlink the raw URL.

Crops of Steam screenshots (2560x1440, the HUD kept out), scaled to 560 wide as the folder's other pictures (Pillow,
Lanczos), made 2026-10-28 with the pack's 1.0.0 release build. The crop box is given as left,top-right,bottom in the
screenshot, so a re-shoot from the same spot can be cut the same way.
