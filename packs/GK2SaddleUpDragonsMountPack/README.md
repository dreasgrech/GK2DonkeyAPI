# GK2 Saddle Up: Dragon

A mount pack for GK2 Saddle Up: a dragon to ride, 128 pixels tall, that flies, has young and pulls no cart.

- **Needs:** GK2 Donkey API 0.40.0 or newer and GK2 Saddle Up (it offers the mounts to ride).
- **Install:** put the folder `GK2SaddleUpDragonsMountPack` into `BepInEx\plugins\` (the zip has it so; or extract the zip into
  `Mods\Code\GK2SaddleUpDragonsMountPack\` in the save data folder on game 1.011 or newer, and the game's Mods window lists and installs it):
  `BepInEx\plugins\GK2SaddleUpDragonsMountPack\GK2SaddleUpDragonsMountPack.dll`, a plugin with the pack's files inside. To update, replace it.
- **In the game:** the Mounts panel (Saddle Up's settings) lists the Dragon; pick it and ride.
- **Remove:** delete the folder `GK2SaddleUpDragonsMountPack`. A saved dragon waits as "not installed" and comes back when the pack does.

The mount: `saddleup-dragon.dragon` (its `mount.cfg`: the facts, its jump with its wings, its sounds), its look
`saddleup-dragon.dragon/default`. Its files in the repo: `packs/GK2SaddleUpDragonsMountPack/gk2mounts/`; the pack format: docs/skins.md and docs/making-a-mount.md.
