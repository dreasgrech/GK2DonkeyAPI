[line]
[size=5][b][color=#f0b45a]Keys[/color][/b][/size]

[list]
[*][size=3][b]H[/b] — your donkey comes and you ride. Riding: get off. Driving: leave the cart standing and ride on.[/size][/*]
[*][size=3][b]G[/b] — your donkey comes with its cart and you drive. Riding: the cart comes and is hitched. Driving: get off.[/size][/*]
[*][size=3][b]E[/b] — at your donkey: get on. At the cart holding something: load it. At the back of the cart with empty hands: take the top item. Driving with nothing in front: set the top item down behind the cart (a chest too).[/size][/*]
[*][size=3][b]B[/b] — ring the bell.[/size][/*]
[*][size=3][b]Send the donkey away[/b] (no key until you set one) — your donkey, cart and foals go; the load is set down first. H or G calls one again.[/size][/*]
[/list]
[size=3]All keys can be changed. You get off by yourself for work, ladders, fishing, sleep and at building doors.[/size]

[line]
[size=5][b][color=#f0b45a]Settings[/color][/b][/size]

[size=3]In the game's [b]Settings[/b] window (in the pause menu and the main menu), the [b]GK2 Saddle Up options[/b] button opens Saddle Up's own options. The Mounts panel (L) has an [b]Options[/b] button too, and with [url=https://www.nexusmods.com/graveyardkeeper2/mods/42]GK2 Mod Framework[/url] installed, Saddle Up's [b]Settings[/b] button in its Mods menu opens them as well. To set a key, click its box and press the key. Everything is also in [i]BepInEx\config\dreas.gk2.saddleup.cfg[/i], to edit with the game closed.[/size]

[center][img]https://raw.githubusercontent.com/dreasgrech/GK2DonkeyAPI/main/media/options-window.png?v=1[/img][/center]

[size=5][b][color=#f0b45a]Install[/color][/b][/size]

[list=1]
[*][size=3]Install the [url=https://www.nexusmods.com/site/mods/115]BepInEx 5 mod[/url] (or download from [url=https://github.com/BepInEx/BepInEx/releases]official repo[/url], v5.4.23 or newer) into the game folder and start the game once.[/size]

[center][img]https://raw.githubusercontent.com/dreasgrech/GK2DonkeyAPI/main/media/BepInEx-files.png?v=2[/img][/center]
[/*]
[*][size=3]Extract the download into the game folder (where [i]GraveyardKeeper2.exe[/i] is).
It adds the folders [b]GK2DonkeyAPI[/b] and [b]GK2SaddleUp[/b] to [i]BepInEx\plugins[/i].[/size]
[/*]
[*][size=3]Start the game. Press [b]H[/b] to call your donkey and [b]G[/b] to call the cart.[/size][/*]
[/list]

[size=3][b]Safe for your save.[/b] Nothing in your save is ever touched: a save with a donkey loads fine without the mod, the donkey simply waits in its own small file next to the save.

[b]Game updates.[/b] Built for Steam game v1.010. After a game update the mod checks the game's code at start; if the game changed under it, the affected part stays off and the log says so.

[b]Uninstall.[/b] Unload the cart and set any chest down first, so nothing is left riding on it. Then delete the folders [b]GK2DonkeyAPI[/b] and [b]GK2SaddleUp[/b] from [i]BepInEx\plugins[/i]. Your saves still load without them.

[b]Found a bug?[/b] Report it in the [url=https://www.nexusmods.com/graveyardkeeper2/mods/391?tab=bugs]Bugs tab[/url] and attach [i]BepInEx\LogOutput.log[/i] from the game folder (it is rewritten each time the game starts, so grab it right after the problem).[/size]

[size=5][b][color=#f0b45a]One visual limitation[/color][/b][/size]

[size=3]Unfortunately, although the donkey can move in any direction, since the game only has left and right facing donkey sprites, those are the only two directions I could have the donkey face in visually.  This means that when you go up or down, the donkey will still keep facing the left/right direction but this is only a visual thing.

In the future I am planning to investigate with external assets so maybe we can have sprites of the donkey which face up and down.  That would be cool.[/size]

[line]
[size=5][b][color=#f0b45a]A work in progress[/color][/b][/size]

[size=3]This is a big mod and it has taken a lot of time to arrive to it's current state and a lot of testing was involved as well.  But all my testing was conducted in the starting areas and that's because I have spent more time developing this mod than actually playing the game, which means that there are areas in the game where I haven't yet been able to test the donkeys.

So it would be immensely appreciated if you let me know what issues you encounter when using the donkey in different places.

One other thing is the cargo on the cart, and I currently support up to six carryable items on the cart and as you can image, given the amount of different carryable items in the game and the cart supporting up to six different items, there are lot of different combinations of cargo layout configurations.
If you encounter any cargo set of items on the cart which doesn't look right, please also let me know about it so I can fix it.

I would say that most of the combinations of cargo items look alright but there are a lot.[/size]

[line]
[size=5][b][color=#f0b45a]For modders[/color][/b][/size]

[size=3]The way I've built this mod is in two parts: the [b]GK2 Donkey API[/b] mod and the [b]Saddle Up[/b] mod. The Donkey API mod does the heavy lifting and can be used by mod authors to gain full control of the donkey functionalities that are demonstrated on this page and more, while this Saddle Up mod is a full playable showcase of most the features that the Donkey API exposes.

This SaddleUp mod download already contains the DonkeyAPI bundled with it because it needs it to work since it's build on top of it, but I will later be creating a separate page on here for the DonkeyAPI where it could be downloaded separately as well.

This is because multiple mods can make use of the DonkeyAPI and unless they are specifically doing the same things, there will not be clashes.  This allows anyone who wants to create anything with the donkey to call the api and do whatever they want with it.

The full source code will also come with it.[/size]
